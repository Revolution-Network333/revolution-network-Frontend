Opérations disponibles

Ce que tu peux faire

filter
Filtrer les lignes selon des conditions complexes (AND/OR/NOT).
map / transform
Calculs de champs, concaténation, formatage de dates, normalisation.
aggregate
SUM, COUNT, AVG, MIN, MAX, GROUP BY sur n'importe quelle colonne.
join
Joindre deux datasets sur une clé commune (INNER, LEFT, RIGHT JOIN).
deduplicate
Supprimer les doublons selon une ou plusieurs colonnes clé.
pivot / unpivot
Restructurer un dataset de format long à large ou inversement.
sort
Tri multi-colonnes, ordre croissant/décroissant, support des types.
sample
Échantillonnage aléatoire ou stratifié pour les workflows ML.
encode / decode
Base64, URL encoding, JSON parse, conversion de charsets.
