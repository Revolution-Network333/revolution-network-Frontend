Intégration

Trois appels curl. C'est tout.

Pas de SDK, pas de configuration de région, pas de proxy à câbler.

bash
# Submit scraping job curl -X POST https://api.revolution-network.fr/api/enterprise/v1/jobs \ -H "x-api-key: YOUR_KEY" \ -d '{"type":"scrape_get","params":{"url":"https://example.com","mode":"browser"}}' # Response → { "job_id": "jb_abc123" } # Get result curl https://api.revolution-network.fr/api/enterprise/v1/jobs/jb_abc123/result \ -H "x-api-key: YOUR_KEY" # CSS mode — structured extraction curl -X POST https://api.revolution-network.fr/api/enterprise/v1/jobs \ -H "x-api-key: YOUR_KEY" \ -d '{ "type":"scrape_get", "params":{ "url":"https://shop.example.com", "mode":"css", "selectors":{"price":".price-current","stock":"[data-stock]"} } }' # Response → { "data": { "price": "€29.99", "stock": "in_stock" } }
